# 快速开始

从安装到跑通第一个带工具的 Agent 循环，约 5 分钟。

## 安装

```bash
go get github.com/dingkui/dlz-goai
```

要求 Go 1.24+。核心包零第三方依赖；只有 `storage/sqlite` 引入 modernc.org/sqlite（纯 Go，无 CGO）。

## 准备一个模型服务

任选其一：

- **本地 Ollama**：[安装 Ollama](https://ollama.com) 后 `ollama pull qwen3:8b`（或任意支持工具调用的模型）
- **OpenAI 兼容服务**：OpenAI / DeepSeek / 通义 / 本地 vLLM 等，拿到 base URL 与 API key

## 最小对话（无工具）

```go
package main

import (
	"context"
	"fmt"

	"github.com/dingkui/dlz-goai/message"
	"github.com/dingkui/dlz-goai/provider/ollama"
)

func main() {
	provider := ollama.New("") // 空 = http://127.0.0.1:11434

	var out string
	err := provider.ChatStream(context.Background(), "qwen3:8b",
		[]message.Message{{Role: message.RoleUser, Content: "用一句话介绍你自己"}},
		nil,
		func(d message.Delta) {
			if d.Content != "" {
				fmt.Print(d.Content)
				out += d.Content
			}
		})
	if err != nil {
		fmt.Println("调用失败:", err)
	}
	_ = out
}
```

OpenAI 兼容服务把前两行换成：

```go
provider := openai.New("https://api.deepseek.com", "sk-...")
// 或按配置构造：provider := factory.NewProvider(llm.Service{Kind: "openai", ...})
```

## 加上工具（Agent 循环）

工具就是普通 Go 函数。`readOnly=true` 的工具默认直接执行：

```go
provider := ollama.New("")

tools := []tool.Tool{
	tool.NewFunc("get_time", "获取当前本地时间", nil, true,
		func(context.Context, map[string]any) (tool.Result, error) {
			return tool.Text(time.Now().Format(time.RFC3339)), nil
		}),
}

callModel := func(ctx context.Context, msgs []message.Message, opts *message.Options, cb func(message.Delta)) error {
	return provider.ChatStream(ctx, "qwen3:8b", msgs, opts, cb)
}

result, err := agent.New().Run(
	context.Background(),
	[]message.Message{{Role: message.RoleUser, Content: "现在几点了？用一句话回答"}},
	nil,
	agent.Config{Tools: tools},
	callModel,
	func(e agent.Event) {
		switch e.Type {
		case agent.EventModelDelta:
			fmt.Print(e.Content)
		case agent.EventToolResult:
			fmt.Printf("\n[工具 %s 返回 %s]\n", e.ToolName, e.Result)
		}
	},
)
```

模型会请求调用 `get_time`，循环自动执行工具并把结果回传，直到模型给出最终回答。`result.Content` 是最终回答，`result.Steps` 是循环步数。

## 运行官方示例

```bash
# 进程内工具的完整循环（需要本地 Ollama）
go run ./examples/minimal

# 有副作用的工具执行前等待人工确认（模拟界面批准）
go run ./examples/approval

# 把一个 MCP server 的工具接入 Agent（stdio 传输）
go run ./examples/mcp
```

## 需要断点续跑时

默认的 `agent.Run` 是进程内一次性的。长任务、需要跨重启恢复时换用 `runtime`：

```go
db, opts, err := sqlite.OpenRuntime("runs.db") // 一行装配三个持久化 Store
if err != nil {
	panic(err)
}
defer db.Close()
rt := runtime.New(opts)

runID := rt.BeginRun()
result, err := rt.Run(ctx, msgs, nil,
	agent.Config{RunID: runID, Tools: tools}, callModel, nil)

// 进程重启后：登记恢复 + 从检查点续跑（工具由调用方重新提供）
rt.Recover(ctx)
result, err = rt.Resume(ctx, runID, agent.Config{Tools: tools}, callModel, nil)
```

详见 [runtime 手册](使用手册/runtime.md)。

## 常见报错速查

| 现象 | 原因与处理 |
|---|---|
| `agent: no model function provided` | `agent.Config.Run` 的 model 参数传了 nil；传一个 `ModelFunc`（通常一行适配 provider.ChatStream） |
| 服务端 400 提示 does not support tools | 模型不支持 function calling；换支持工具调用的模型，或去掉 `Config.Tools`（空工具集自动退化为普通对话） |
| 非只读工具直接返回 "not approved by the user" | 没有配置 `Config.Approve`——默认安全策略是未配置即拒绝。需要审批就传 `ApprovalHandler`（如 `agent.Broker`），确定不需要就把工具声明为只读 |
| Ollama 连接失败 | 确认 `ollama serve` 在跑；`ollama.New("")` 默认连 `http://127.0.0.1:11434`，远程服务传完整地址 |
| `runtime: cfg.RunID is empty` | 用 `runtime` 时必须先 `runID := rt.BeginRun()` 再放进 `agent.Config.RunID` |
